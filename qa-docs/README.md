Du kan uppdatera befintliga filer eller lägga till nya guider. Använd gärna tydliga rubriker, korta stycken och gärna både svenska och engelska om möjligt.

## 🇬🇧 English

This folder (`docs/`) contains documentation for the `qa-docs` project.  
The purpose is to provide useful information to help new and current team members understand the project goals, testing strategy, and routines.

### What's included?
- `onboarding.md`: Guide for onboarding new QA team members

### How to contribute?
Feel free to update existing documents or add new ones. Use clear headings, short sections, and preferably include both Swedish and English when possible.
