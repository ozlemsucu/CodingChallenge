# 🔁 CI Workflow

## 🇸🇪 På svenska

Detta dokument beskriver den automatiserade CI-processen (Continuous Integration) för QA-projektet.

### Steg
1. Push till GitHub
2. GitHub Actions kör tester automatiskt
3. Resultat visas på GitHub och Codecov

---

## 🇬🇧 In English

This document describes the automated CI process for the QA project.

### Steps
1. Push to GitHub
2. GitHub Actions run tests automatically
3. Results are displayed on GitHub and Codecov
