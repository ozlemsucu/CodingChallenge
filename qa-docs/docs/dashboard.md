# 📊 Dashboard – Översikt och uppföljning

## 🇸🇪 På svenska

Dashboarden visar status för projektets testning, kodkvalitet och testtäckning. Den är tänkt att ge teamet en snabb översikt.

### Innehåll
- ✅ Senaste testresultat
- 📈 Testtäckning från Codecov
- 🚥 Status på GitHub Actions
- 📊 Eventuella diagram för fel eller buggar

Används under morgonmöten eller vid kodgranskningar för att fatta beslut snabbare.

---

## 🇬🇧 In English

The dashboard provides an overview of the project's testing progress, code quality, and coverage. It helps the team stay up to date.

### Includes
- ✅ Latest test results
- 📈 Code coverage via Codecov
- 🚥 GitHub Actions build status
- 📊 Charts for bugs or issues

Used during daily standups or code reviews to guide decisions.
