# 🚀 Getting Started

## 🇸🇪 Kom igång

Den här guiden hjälper nya QA-medlemmar att komma igång med projektet. Här finns instruktioner för installation, kodstruktur och viktiga verktyg.

### Steg för att komma igång
1. Klona GitHub-repot
2. Installera Node.js och npm
3. Kör `npm install`
4. Kör tester med `npm test`

## 🇬🇧 Get Started

This guide helps new QA members get started with the project. It covers installation steps, code structure, and important tools.

### Steps to get started
1. Clone the GitHub repo
2. Install Node.js and npm
3. Run `npm install`
4. Run tests using `npm test`
