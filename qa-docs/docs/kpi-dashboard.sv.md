# KPI Dashboard / KPI-instrumentpanel

## Svenska 🇸🇪  
Den här sidan visar våra nyckeltal (KPI:er), som hjälper oss att följa upp kvalitet, testresultat och projektmål. KPI-dashboarden används för att få en snabb överblick över projektets status.

## English 🇬🇧  
This page presents our key performance indicators (KPIs), which help us track quality, test results, and project goals. The KPI dashboard gives a quick overview of the project's status.
