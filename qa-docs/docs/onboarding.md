# 👋 Onboarding – QA Teamet / QA Team

## 🇸🇪 Svenska

Välkommen till QA-teamet i Project 54! Här är en snabbguide för att komma igång.

### Vad du behöver:
- GitHub-konto
- VS Code installerat
- Grundläggande Git och terminalkunskap

### Så här börjar du:
1. Klona `qa-docs`-repon från GitHub
2. Öppna mappen i VS Code
3. Kör tester med:

```bash
npm install
npm test
```

👉 Om något krånglar, kontakta David eller Özlem.

## 🇬🇧 English

Welcome to the QA team in Project 54! This guide will help you get started.

### What you need:
- A GitHub account
- VS Code installed
- Basic knowledge of Git and command line

### Getting started:
1. Clone the `qa-docs` repository from GitHub
2. Open the folder in VS Code
3. Run tests using:

```bash
npm install
npm test
```

👉 If you run into problems, contact David or Özlem.
