# Security Checklist / Säkerhetschecklista

## Svenska 🇸🇪  
En checklista för säkerhetsåtgärder i projektet. Den inkluderar punkter som hantering av användarbehörigheter, dataskydd och kodgranskning.

## English 🇬🇧  
A checklist for security measures in the project. It includes items such as user access management, data protection, and code review.
